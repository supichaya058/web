จากข้อมูล Scopus ที่รวบรวมมา หลังจากตัดรายการบทความที่ซ้ำกันแล้ว มีทั้งหมด 599 publications

เราเลือกใช้ Author Keywords ในการวิเคราะห์เพื่อดูว่า หัวข้อวิจัยใดปรากฏบ่อยที่สุด

จากกราฟพบว่า Machine Learning เป็น keyword ที่พบมากที่สุด จำนวน 29 publications รองลงมาคือ Artificial Intelligence จำนวน 26 publications และ Deep Learning จำนวน 15 publications

เมื่อมองภาพรวมจะเห็นว่า งานวิจัยมี AI และ Machine Learning เป็นกลุ่มหลัก แต่ไม่ได้จำกัดอยู่เฉพาะ Software เท่านั้น เพราะยังมี FPGA, Hardware Security, Edge Computing และ Edge AI

ดังนั้นภาพรวมของ Dataset นี้สามารถตีความได้ว่า งานวิจัยกำลังมุ่งไปทาง AI + Computing + Hardware + Edge Technology
